# VLC Global EQ

A small Android app (minSdk 28) that applies a VLC-style 10-band equalizer to **all audio on the phone**. No root, Shizuku or ADB needed. Presets import straight from VLC for Android's JSON export.

The EQ runs as Android's `DynamicsProcessing` effect on audio session 0 (the global output mix). The DSP runs inside AudioFlinger, so it adds no latency and the app itself does almost no work. A foreground service only keeps the effect object alive.

## Build

```
./gradlew testDebugUnitTest assembleRelease
```

CI (`.github/workflows/build.yml`) runs the unit tests, builds debug and release APKs and uploads them as artifacts. The release build is signed with the debug key so it installs directly; use your own key to distribute it. The app has no dependencies beyond the Android framework.

## How it works

| Part | File |
|---|---|
| DynamicsProcessing on session 0, plus per-session instances | `audio/EqEngine.kt` |
| VLC's 10 points → 28 DP bands (PCHIP in log-frequency) | `audio/CurveMapper.kt` |
| (v2, experimental) libVLC's exact IIR magnitude response | `audio/VlcResponse.kt` |
| VLC JSON import (single / array / wrapped) and export | `data/VlcImporter.kt` |
| VLC's built-in presets, generated from libVLC source | `data/BuiltinPresets.kt` ← `tools/gen_builtin_presets.py` |
| Foreground service, boot receiver, session receiver, QS tile | `service/` |
| UI (Views built in code, no layouts) | `ui/` |

### Things verified against libVLC source

- **Band frequencies.** VLC for Android uses libVLC, whose media player creates `equalizer-vlcfreqs` without a value. That means it's false, so libVLC uses the ISO bands (31.25 Hz … 16 kHz), and `libvlc_audio_equalizer_get_band_frequency` returns the same table. Desktop VLC uses its own set (60 Hz … 16 kHz), available here as `BandSet.VLC10`.
- **Preamp offset.** libVLC's filter output is `preamp · (0.25·x + Σ band outputs)`, so a flat preset with preamp P plays at **P − 12.04 dB**. That's why VLC's built-in presets use preamps around +12 dB. The engine applies the same offset, so a VLC preset plays at the same loudness here as in VLC. The UI and exports keep VLC's raw preamp value.
- **Built-in presets.** The 18 presets in `equalizer_presets.h` are generated by a script. VLC's `-1.11022e-15` "zero" values become `0.0`.

### Settings (⋮ menu)

- **Mode:** Global (recommended) / Per-app sessions / Both. Per-app mode only covers players that send `ACTION_OPEN_AUDIO_EFFECT_CONTROL_SESSION`. In *Both*, per-session effects stay off until the global effect is lost or unavailable, so audio is never equalized twice.
- **Auto preamp:** input gain = −max(curve gain), so the curve never boosts above 0 dB. This ignores the preset's own preamp.
- **VLC-exact curve (experimental):** samples libVLC's real filter-bank response instead of the interpolated curve.

A limiter is always on (attack 1 ms, release 60 ms, ratio 10:1, threshold −1 dBFS).

## Known limits

- Audio sent to hardware offload or a direct output (some music players, bit-perfect USB DAC modes, some games) bypasses AudioFlinger effects. There's no fix without root.
- Only one app can control the session-0 slot. Wavelet, RootlessJamesDSP and Dolby/OEM effects can take it over. The app then shows "Lost control to another EQ app" and doesn't fight back.
- VLC's own equalizer stacks with this one. Set it to Flat or turn it off.
- If the EQ stops after a while, the phone is killing background apps. Allow the app to ignore battery optimisation and see https://dontkillmyapp.com.

## On-device checks

1. `adb shell dumpsys media.audio_flinger`: a DynamicsProcessing effect should be listed on session 0.
2. Play 31 Hz / 1 kHz / 16 kHz test tones from YouTube, Spotify and a game. Each level should follow its matching slider.
3. Swipe the app away from recents: the EQ stays on. Reboot: the EQ comes back without opening the app.
4. Enable Wavelet: the status should switch to "Lost control to another EQ app".
